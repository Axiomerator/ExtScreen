ExtScreen · Windows 快速开始

1. 升级时先从系统托盘退出旧版。将 ExtScreen-Windows-x64.zip 完整解压，升级时可覆盖原目录，随后双击 ExtScreen.exe。
2. 初次使用时，在「设置 → 虚拟显示驱动」中安装驱动，并确认 Windows 管理员授权。
3. 在安卓设备上打开 ExtScreen，通过 USB 或局域网连接电脑。驱动就绪后重新连接即可使用扩展屏。
4. 在 Windows 的「设置 → 系统 → 显示」调整扩展屏的位置。需要卸载驱动时，先断开安卓设备，再在控制面板操作。

support 目录包含后台程序、辅助工具和说明。USB 直连或网络共享遇到问题时，查看 support\README.md。
